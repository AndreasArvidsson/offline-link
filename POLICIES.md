# Privacy and code signing policy

## Privacy

OfflineLink stores tournament data, including player names and match results, in JSON files in `Documents/OfflineLink` on your computer. It does not upload this data or include analytics, telemetry, or automatic crash reporting. The released application loads its interface and assets locally and does not require an internet connection.

If your Documents folder is managed by a cloud synchronization service, that service may synchronize these files according to your settings and its privacy policy.

## Code signing policy

Windows releases are currently unsigned. We intend to apply for free code signing through SignPath Foundation. Approval has not been granted. The following roles describe the proposed signing responsibilities:

- Committer and reviewer: [Andreas Arvidsson](https://github.com/AndreasArvidsson), responsible for maintaining the source code and reviewing external contributions.
- Signing approver: [Andreas Arvidsson](https://github.com/AndreasArvidsson), responsible for manually approving each release submitted for signing.

See [Privacy](#privacy) for information about data storage and network behavior.
